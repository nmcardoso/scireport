## Done in S5

- **pandoc** (`scireport[pandoc]`, lazy): `render.markup_engine: mistletoe | pandoc` with no automatic switching; the
  pandoc version in `render-manifest.json` and `render.pandoc_version` (set by `pack`), `W501` on a mismatch. Prose runs
  under `--sandbox`. Golden outputs for both engines (`tests/golden/markup/`) and the list of differences in
  `docs/markup.md`.
- **Citations**: the `bibliography` kind, `[@key]` in Markdown text values, `c.references()`; citeproc once per document
  for md and html, biblatex + biber for tex (no pandoc). `E211`, `E212`, `E506`, `E507`.
- **docx, odt, epub** from the unsplit Markdown (or `--office-source html`), optional `reference.docx`; reproducible.
- **`scireport export tex`**: `tab_<key>.tex`, `fig_<key>.tex`, `numbers.tex`; a test compiles a stub manuscript.
- **CLI**: `render`, `validate`, `pack`, `unpack`, `inspect`, `new`, `preprocess`, `export tex`, `templates [NAME]`,
  `layouts [NAME]`, `preprocessors [NAME]`, `spec`, `mplstyle`, `agent install-skill|mcp-config`, `mcp serve`; exit codes
  0/1/2/3; `--json` on the commands agents use. Public `__all__` (37 names) with a snapshot test.
- **MCP server** (SDK 2.x `MCPServer`, stdio) with the ten tools, the skill pages as resources, paths confined to
  `--root`; tested with the SDK's in-memory client.
- **Skill**: `SKILL.md` + 8 reference pages, tables generated by `make skill` and drift-tested; `error_help.HELP` for
  every code. The pages were written by sonnet subagents and their examples were run; I read the reports, not every line.
