# scireport

Data-centric scientific report engine. One **data file** (a report bundle), one **template** and one **layout**
are rendered to Markdown, HTML, LaTeX and PDF.

This site is under construction. The design is recorded in the architecture decision records; the
specification, API and reference pages arrive with phases S1 to S6.
