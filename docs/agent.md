# The agent skill

A coding agent that has to produce or debug a report needs more than `--help`: the data-file format, the template
rules, what the error codes mean and the usual recipes. `scireport` ships all of that as a **skill** (a folder with a
`SKILL.md` and reference pages, in the format Claude Code and other agents load) and, in addition, serves it through an
[MCP server](mcp.md). Both are generated from, or served by, the installed package, so they cannot describe another
version.

## Get the skill

Two ways, giving the same files:

```console
$ scireport agent install-skill --dest .claude/skills          # copy the installed package's skill into a project
$ scireport agent install-skill --dest .claude/skills --check  # exit 1 when the copy differs (for CI)
```

or download [scireport-skill.zip](https://nmcardoso.github.io/scireport/downloads/scireport-skill.zip) from this site
and unpack it into `.claude/skills/` (or the skills folder of your agent), which gives `scireport/SKILL.md` and
`scireport/references/`. The archive is reproducible: the same version gives the same bytes. Unlike `install-skill`, it
comes from the version of the package that built this site, which may be newer than the one you installed.

## What is in it

`scireport/agent/skill/scireport/` holds `SKILL.md` and `references/` (`data-file.md`, `python-api.md`, `cli.md`,
`templates-and-layouts.md`, `preprocessors.md`, `mplstyle.md`, `errors.md`, `recipes.md`). `SKILL.md` follows the
monorepo frontmatter rules: `name` equals the folder name and `description` has at most 1024 characters.

The tables in the references (commands and options, value kinds, manifest fields, public API, components, filters,
layouts and their options, pre-processors, error codes) are generated from the code by `make skill`; a test fails
when a page is stale. The pages of this site that carry the same tables are generated by the same code, so the skill and
the site agree.

## The skill, the site and the MCP server

| Use | When |
|---|---|
| The **skill** | the agent works in a project that installs `scireport`; it needs the instructions offline, in its own context |
| This site's **`llms.txt`** and **`llms-full.txt`** | the agent has no install yet (it must decide whether to use `scireport`, or write the first bundle); [llms.txt](https://nmcardoso.github.io/scireport/llms.txt) lists the pages, [llms-full.txt](https://nmcardoso.github.io/scireport/llms-full.txt) is all of them in one file |
| The **MCP server** | the agent should call scireport as tools (describe a template, validate, render) inside a directory you choose: see [MCP server](mcp.md) |

Every page of the site also has a Markdown twin: replace `.html` by `.md` in its address.
